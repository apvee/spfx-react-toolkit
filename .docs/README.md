# Internal working documentation

This directory contains repository maintenance and agent working material.

- [Maintenance record](maintenance/PROGRESS.md): versioned decisions, findings, reviews, and verification evidence.
- `superpowers/`: local planning/specification material, ignored by Git.

Public product documentation is in [docs/](../docs/). Agent instructions remain in [AGENTS.md](../AGENTS.md). Runtime and API test fixtures are in [tests/fixtures/](../tests/fixtures/).

Historical logs and plans retain the file paths used when their commands were executed. Current links and working conventions use `.docs/`.
